# 天气预报 APP
Android 课程设计作业
**完成时间**：2024.12.24

## 📋 项目简介
本项目是一款基于 **Android 原生开发**的综合天气预报应用，采用 **MVVM 架构**，整合高德地图、网络请求、本地数据库、第三方登录、图表可视化、相机拍照、二维码生成等多项技术。
应用采用底部 Tab 栏实现多模块切换，包含**登录注册、地图定位、天气查询、推荐功能、历史数据、系统设置**六大核心板块，支持多城市天气查看、历史数据可视化、城市三级联动选择、自动登录、头像修改、第三方微博登录等完整业务功能，适配 Android 10 ~ Android 14 主流系统版本。

## ✅ 功能总览
### 一、登录模块
-  账号密码注册、账号密码登录
-  第三方微博授权登录
-  基于 SharedPreferences 实现自动登录功能

### 二、主框架
-  底部 Tab 栏实现四大核心功能页面切换（类微信布局）
-  整体采用 **MVVM 架构**，结合 Lifecycle、LiveData、Room 组件开发

### 三、地图模块（高德地图）
-  集成高德地图 SDK，自动定位当前默认城市
-  修改设置页默认城市后，地图实时同步切换定位城市

### 四、天气模块-今日天气
-  展示多城市实时天气信息
-  使用 `CardView` 卡片样式展示基础天气数据
-  结合 `ExpandableListView + RecyclerView` 展示详细天气列表
-  支持查看单城市、多日期天气详情

### 五、天气模块-推荐功能
-  实现二维码生成功能
-  调用系统相机，完成「每日一图」拍摄与图片展示

### 六、历史天气模块
-  基于 **Room 本地数据库** 存储历史城市天气数据
-  气温、湿度、风力风向数据图形化展示（折线图、柱状图、气泡图）
-  可自定义历史页面展示城市数量

### 七、设置模块
-  支持修改登录密码、上传/更换用户头像
-  自定义**三级联动城市选择器**，自由选择城市
-  支持设置默认城市、添加关注城市
-  切换默认城市后全局实时生效并提示
-  可配置历史页面展示城市条数
-  SharedPreferences 持久化配置，实现自动登录开关

### 八、其他
-  兼容测试：Android 10（API29）、Android 14（API34）双版本运行测试
-  规范代码分层管理，模块化解耦

## 🛠 技术栈 & 核心组件
### 整体架构
- 架构模式：**MVVM**
- 核心组件：Lifecycle、LiveData、ViewModel、Room 数据库

### 网络与接口
- 网络请求：Retrofit 封装网络服务，调用天气接口、定位接口
- 第三方 SDK：高德地图 SDK、微博登录 SDK

### 视图与控件
- 基础控件：CardView、RecyclerView、ExpandableListView、BottomNavigationView
- 图表框架：HelloCharts（实现折线图、柱状图、气泡图数据可视化）
- 图片加载：Glide
- 二维码：自定义二维码生成工具类
- 设置页面：PreferenceFragmentCompat

### 数据存储
- 本地数据库：Room（ORM 框架，替代原生 SQLite）
- 轻量存储：SharedPreferences（配置项、自动登录、用户偏好）

### 权限与系统能力
- 动态权限申请：相机权限、定位权限、相册权限
- 相机调用：系统原生相机实现拍照功能
- 相册回调：实现头像选择与图片回显

## 🧩 核心重难点实现说明
### 1. Room 数据库问题解决
项目使用 Room 替代原生 SQLite 管理用户数据、城市天气数据。
- 问题：数据库字段迭代、ViewModel 跨 Fragment 共享、数据库主线程操作崩溃、空指针异常。
- 解决方案：
  1. 规范 Repository 层初始化，通过 Context 获取数据库实例与 DAO；
  2. 使用 `ExecutorService` 线程池，将数据库增删改查操作放置在子线程执行；
  3. 结合日志逐层排查 ViewModel、Repository、DAO 调用链路，保证数据流转正常。

### 2. 高德地图在 Fragment 中显示
- 问题：高德地图原生方案在 Fragment 中无法正常渲染、定位不更新。
- 解决方案：
  1. 封装 `BaseFragment` 基础基类，地图 Fragment 继承基类并重写定位、相机位置相关方法；
  2. 结合 LiveData 监听默认城市变更，通过逆地理编码将城市名转为经纬度；
  3. 实时更新地图相机位置，实现「修改默认城市 → 地图自动切换定位」联动效果。

### 3. 微博第三方登录接入
- 问题：网络教程适配性差，Fragment 中无法完成微博授权。
- 解决方案：
  1. 参考微博官方文档与官方 Demo，基于 Activity 实现授权逻辑；
  2. 使用 Fragment 作为中转页面，跳转授权 Activity，接收授权 Token 后完成登录逻辑。

### 4. 相机权限与拍照功能
- 问题：Android 高版本相机权限限制，调用相机直接闪退、初始化空值。
- 解决方案：
  1. 使用 `registerForActivityResult` 新 API 实现**动态权限申请**；
  2. 先申请相机权限，权限通过后再启动拍照流程；
  3. 对拍照返回 Bitmap 做缩放、空值判断，防止 Fragment 生命周期异常导致崩溃。

### 5. 头像上传与相册回调
- 问题：自定义偏好设置类无法接收相册图片回调，头像路径无法存入数据库。
- 解决方案：
  遵循「谁发起、谁回调」原则，将相册选择逻辑迁移至 SettingFragment 中处理，获取图片 Uri 后同步更新 UI 与本地数据库。
